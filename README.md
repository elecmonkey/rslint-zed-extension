# Rslint for Zed

Experimental Zed extension for Rslint, with the language-server worker sourced from upstream [`rstackjs/rstack-editor`](https://github.com/rstackjs/rstack-editor).

For local use, run `git submodule update --init && pnpm install && pnpm build`, then install this directory with Zed's **Install Dev Extension**.
